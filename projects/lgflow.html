What it is

LG-FLOW is a 2D incompressible Navier-Stokes solver written in C++20. It uses the finite volume method (FVM) with SIMPLE pressure-velocity coupling on a staggered grid. It is validated against the Ghia et al. (1982) lid-driven cavity benchmark at Re = 100 and Re = 1000. It outputs per-iteration residuals, centreline velocity profiles, VTK snapshots and L2/L∞ error metrics.

Validation: Ghia et al. lid-driven cavity

The reference is Ghia, Ghia & Shin (1982), the standard benchmark for 2D incompressible lid-driven cavity flow. Both cases, Re = 100 and Re = 1000, pass automated L2 and L∞ error thresholds.

Case Re Reference Status
Lid-driven cavity 100 Ghia et al. 1982 PASS
Lid-driven cavity 1000 Ghia et al. 1982 PASS

The check is automated. The solver exits with a non-zero code if any metric is outside tolerance, so CI can use it directly.

Implementation

01Staggered grid with collocated pressure, which avoids pressure-velocity decoupling
02SIMPLE pressure-correction loop with a configurable number of passes
03Consistent stencils: one interpolation scheme everywhere
04Automated validation with pass/fail exit codes
05VTK export for post-processing in ParaView
