FauxMatlab: a control-systems workbench in Python

A desktop workbench for classical and state-space control. It has analysis plots, a block-diagram simulator and a MATLAB-style command window. Python and PySide6, 684 tests.

Back to projects View repo ↗

What it does

FauxMatlab covers the parts of MATLAB, Simulink and the Control System Toolbox that two control courses use: CLACO (classical, frequency domain) and DYBAC (state space). It is one PySide6 application with three workspaces.

Analyse shows responses, margins and stability for the loaded system. Model is a block-diagram editor and simulator. Console is a command window with a workspace browser and a script editor. All three use the same live model, so a change in one appears in the others.

Features

Analysis
Step, impulse and ramp responses, Bode, Nyquist, Nichols, root locus, pole-zero map, Routh table and step metrics. One, two or four panes, all fed by the same model.
Simulator
50 block types, nested subsystems, RK4, RK45 and Euler solvers, and scopes. linearize() extracts a state-space model from a nonlinear diagram.
Command window
59 MATLAB-style commands, including tf, feedback, bode, margin, rlocus, lqr, place, c2d and pidtune.
Design apps
LTI Viewer, a root-locus designer (drag a closed-loop pole and the step response follows) and a PID tuner.

How the numbers are checked

  • Closed-loop transfer functions come from the diagram itself. The solver treats the diagram as a polynomial matrix over ℚ(s) and never cancels poles against zeros. An unstable mode hidden by a cancellation stays visible in the internal-stability check. This replaced twelve hand-derived formulas, six of which were wrong.
  • Discrete blocks sample and hold. A 50 Hz discrete PID changes its output 150 times in 3 s. An earlier version let the continuous error pass through and changed it 1498 times.
  • The PID tuner computes its gains instead of searching for them. At the target crossover frequency, the required magnitude and phase fix the PI gains. margin(C·G) then returns the requested crossover and phase margin to within 1e-14.

Tests and build

684 pytest tests, plus ruff. Most are golden tests: the expected values are computed by hand or by an independent method. The numeric and symbolic solvers check each other, and python-control is a third reference.

PyInstaller builds a one-folder Windows bundle, and --check runs a headless self-test in it. There is no slycot dependency: minreal, gram, modal form and d2c are implemented directly, so a plain pip install works.
