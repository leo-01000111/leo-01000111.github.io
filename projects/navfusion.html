navfusion

Modular sensor fusion for 3D navigation.

An event-driven error-state EKF that fuses IMU and GNSS. It keeps pose estimates stable when measurements are late, missing or noisy.

What it solves

Navigation stacks often degrade sharply when sensor timing or quality moves away from nominal. navfusion is a modular fusion core with predictable behaviour, failures that can be diagnosed, and reproducible validation.

  • Maintains stable state estimation during GNSS dropouts and delayed measurement bursts.
  • Reduces integration effort for mixed-rate, asynchronous sensor pipelines.
  • Provides concrete diagnostics that support safety reviews.

Engineering highlights

  • Event-driven fusion engine for real-time use.
  • Error-state EKF with quaternion attitude representation.
  • IMU propagation plus GNSS position/velocity fusion.
  • Asynchronous sensors with bounded out-of-order handling.
  • Innovation gating and diagnostics that reject bad measurements.
  • Modular design, so new sensor types can be added.

Reliability and validation

Validation is part of the design. The pipelines detect estimator inconsistency early, and every benchmark run is reproducible.

  • NIS/NEES consistency checks integrated in CI.
  • Benchmark artifacts are saved for review after each run.
  • Docs and demo outputs are generated from versioned code.
  • Diagnostics centered on innovation behavior and gate decisions.

Demo scenarios

  1. GNSS dropout handling.
  2. Out-of-order and delayed GNSS robustness.
  3. GNSS outlier rejection with gating.
