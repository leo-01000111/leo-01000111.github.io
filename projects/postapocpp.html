What it does

Past ARPRO exams follow one pattern: a puzzle or a game, one classic algorithm given as pseudocode, and a C++ skeleton with a few methods marked TODO. The kit is built around that. It has a page that tells you which algorithm fits which problem, and a template for each one that compiles on its own.

Everything opens from START_HERE.html. Press Ctrl+K and type erase, priority_queue or a compiler error, typos included, and it jumps to the syntax card, the cheat-sheet card or the exact line of a function. There is also a two-hour exam timer and a checklist for the routine: read the subject, build the untouched project, commit after each working method. The page works from the drive with no network, and it also works online.

What's inside

Cheat-sheets
C++17, the STL with a complexity table, and a decoder for g++, linker and CMake errors. They are Markdown files; a Python script turns them into the page.
Algorithm templates
Backtracking, A*, BFS and DFS, minimax with alpha-beta, a genetic algorithm and memoised recursion. Each demo checks itself: 92 solutions to 8-queens, a 15-move 8-puzzle, alpha-beta cutting Nim from 489k to 58k nodes.
My mistakes
Every slip I made while solving the sudoku exam, written as a rule: member against accessor, -> on pointers, return inside a backtracking loop.
Exam PC tools
Bash scripts: one sets the kit up from the drive, one greps every note, snippet and slide at once, one builds a CMake project with sanitizers so a crash points at its line.
Function reference
150 std functions, one card each: signature, a minimal example, header, complexity and the gotcha that bites (pop_back returns nothing, map[k] inserts). A test compiles all 150 examples.
Debugging
A dbg() macro that prints any variable or container with its name, and a CHECK pattern to test one method before the rest of the program depends on it.

Design

The page uses Holding Point, the design system of this website. Fonts, styles and the search index are inlined, so a single file carries everything. One topic per card and a keyboard-first search, because there is no time to scroll in an exam.

Limits

  • Course slides and exam subjects are not published. A script fetches the public parts; the slides come from the school's Moodle.
  • The templates target one course's exam style. They are starting points, not solutions.
