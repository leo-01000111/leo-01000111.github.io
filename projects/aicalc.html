AICalc

A calculator where the Compute button is a neural network. A GRU seq2seq model and a Transformer predict the answer character by character.

Try it

Type a sum or pick a random one. Both models run in your browser with the real trained weights. Nothing is sent to a server.

a+b or a-b, with a and b from 0 to 127. Random held-out picks an example the models never saw.

Runs in your browser · ONNX Runtime Web (WASM) · no server

What it does

You type an expression such as 7+3 or 20−100. The model reads it as text and writes the answer one character at a time, like a language model. Both models work on addition and subtraction modulo 128, so every number is between 0 and 127.

Architectures

Seq2seq encoder
Bidirectional GRU. Its two final hidden states are averaged to start the decoder.
Seq2seq decoder
GRU with Bahdanau attention. Teacher forcing drops linearly from 100% to 0% during training.
Transformer encoder
Standard encoder-decoder with sinusoidal positional encoding, trained with AdamW and weight decay.
Transformer decoder
Full teacher forcing in training, greedy decoding at inference.

Grokking

Both models grok. Training accuracy rises fast while validation accuracy stays flat, then validation jumps up to match. The Transformer needed about 500 epochs, and without weight decay it never generalised. The seq2seq model stayed near 79% until I made its encoder bidirectional.

Results

Model Architecture Val accuracy
Seq2seq Bidirectional GRU + Bahdanau attention 92.66 %
Transformer Encoder-decoder + sinusoidal positional encoding 96.66 %

Interface

A Tkinter app. You pick a model and a checkpoint, then type on the keypad. The history panel compares each answer with the true result.
